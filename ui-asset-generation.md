# UI Asset & Micro-Visual Generation

Use image generation to create custom visual assets that improve communication, identity, feedback, or product character. This is not general-purpose image generation.

Suitable assets include custom feature icons, small illustrations, empty-state graphics, AI indicators, loading graphics, abstract product graphics, onboarding illustrations, product objects, patterns, and micro-animation concepts.

## Match the interface

Inspect the surrounding visual system before generating. Match palette, stroke, geometry, perspective, lighting, material, contrast, detail level, visual weight, radius language, and density. Multiple assets should feel like one family.

## Design for final size

Small assets require simple silhouettes, clear negative space, controlled contrast, and limited internal detail. An asset that looks impressive at 1024px but becomes unreadable at 24px has failed.

## Keep universal UI icons universal

Do not generate custom versions of close, back, search, settings, menu, chevrons, add, remove, download, upload, share, or delete merely to be different. Custom generation is more useful for product-specific concepts and branded features.

## Keep UI native

Do not bake functional buttons, inputs, tables, menus, or important text into generated images when those elements can be native UI.

## Restraint

Do not fill every empty area with generated artwork. A few coherent custom assets are stronger than visual noise. Generated assets should feel native to the product rather than added afterward.
