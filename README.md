# Design Skills

A modular collection of practical UI design skills for AI-assisted product design.

Design Skills focuses on hierarchy, typography, spacing, information architecture, reading behavior, component quality, visual assets, and other principles that help generated interfaces feel intentionally designed instead of generically AI-generated.

## Skills

- Visual Hierarchy
- Information Architecture
- Typographic Hierarchy
- Spatial Hierarchy & Prospacing
- Reading Patterns (F-Shape / Z-Shape)
- UI Asset & Micro-Visual Generation
- Progressive Disclosure
- Content Chunking
- Nested Structural Layouts
- Functional Grouping
- Contrast & Scale
- Alignment & Grid Structures
- Color Weight & Dominance
- Focus & Attention Mapping
- Proximity & Whitespace Distribution
- Scannability Fields
- Component Craft

Each skill is an individual Markdown file at the repository root so agents can load only the guidance relevant to the current design problem without navigating a deep folder structure.

## Design philosophy

Design relationships before decoration. Use hierarchy, proximity, alignment, typography, spacing, contrast, and restrained component geometry to communicate structure. Avoid generic AI UI habits such as oversized controls, excessive cards, arbitrary pills, extreme corner radii, heavy typography, unnecessary shadows, and decorative effects without a functional reason.

## References

Guidance is informed by established interface-design systems and usability research including Apple Human Interface Guidelines, Material Design, Microsoft Fluent, IBM Carbon, Nielsen Norman Group research, and W3C/WCAG accessibility guidance.
