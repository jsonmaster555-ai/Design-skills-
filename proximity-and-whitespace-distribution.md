# Proximity and Whitespace Distribution

Whitespace is structural. Use distance to communicate relationships and distribute attention.

Related elements should generally sit closer together than unrelated elements. Internal component gaps should usually be smaller than gaps between components, and group spacing should usually be smaller than major section spacing.

Do not distribute whitespace evenly merely for symmetry. Different relationships require different distances.

Give important isolated content enough surrounding space to be recognized, but do not create huge empty areas without structural purpose.

Use whitespace instead of unnecessary borders whenever spacing can communicate the same grouping more quietly.

Avoid inflating controls to create breathing room. Compact controls can live inside spacious pages. Page spacing and component density are different systems.

Use a restrained spacing scale and deviate only for genuine optical correction or layout constraints.

Whitespace should create rhythm: tight relationships, readable groups, clear section transitions, and occasional rest areas.
